- 官方独立域名：[https://3d.21212121.xyz](https://3d.21212121.xyz)

## 🚀 自动部署与 CI/CD
本项目已配置 GitHub Actions 自动化持续集成：
- 当向 `main` 分支提交（Push）或合并代码时，GitHub Actions 会自动通过安全 SSH 密钥同步最新代码至生产服务器 `/www/wwwroot/3d.21212121.xyz`。
